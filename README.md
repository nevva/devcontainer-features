# Dev Container Features

Published to `ghcr.io/nevva/devcontainer-features/<feature>`.

| Feature | What it does |
|---|---|
| [`chrome-mcp`](src/chrome-mcp/NOTES.md) | Claude Code and Copilot CLI in the container drive an agent Chrome on the host through the `chrome-devtools` MCP server. |

`host/` holds scripts that run on the host, not in a container (`host/start-agent-chrome.sh` for `chrome-mcp`).

## Develop

```bash
devcontainer features test -f chrome-mcp .   # autogenerated + scenario tests, needs Docker
```

Publish: run the **Release dev container features** workflow on `main` (bump `version` in the feature's
`devcontainer-feature.json` first). Make the ghcr package public once, after the first release, so containers can
pull it without logging in.
